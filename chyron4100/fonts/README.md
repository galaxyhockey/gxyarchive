# Korinna font files

Fonts 1 to 4 use ITC Korinna. It is a commercial typeface, so the font files
are not in this repository and must not be committed (this folder ignores
them).

Ways to supply it, in the order the emulator looks:

1. **Installed on your computer.** ITC Korinna LT, ITC Korinna Std or
   Bitstream's ITC Korinna is picked up automatically.
2. **Files in this folder.** Copy your licensed files here as
   `korinna-regular.otf` and `korinna-bold.otf`.
3. **Load Fonts key.** Pick the regular and bold files in the page. Files with
   "bold" in the name are used as bold. They are kept in the browser, so this
   is needed once per browser.

Without Korinna the font list marks fonts 1 to 4 as `SUB` and draws them in
Georgia.
